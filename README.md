# Stash Plugins

Plugins for [Stash](https://github.com/stashapp/stash).

## Install

In Stash, go to `Settings` -> `Plugins` -> `Available Plugins` -> `Add source`.

- `Name`: `shalemore`
- `Source URL`: `https://shalemore.github.io/stash-plugins/index.yml`
- `Local path`: `shalemore`

## Plugins

- [Compress Performer Covers](plugins/compress-performer-covers): compresses oversized performer covers to AVIF.
- [E-Hentai Gallery Updater](plugins/eht-updater): fills gallery metadata from E-Hentai folder names.
- [Extended Attributes](plugins/extended-attributes): enforces single-subtype attribute schemas and path-based defaults.
- [IMDb Updater](plugins/imdb-updater): links scenes to IMDb groups and fills TV episode metadata.
